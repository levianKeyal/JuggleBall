JuggleBall - Integración rápida y actualización (versión de main)

1. INSTALACIÓN O ACTUALIZACIÓN

Copia o reemplaza la carpeta src/ completa, manteniendo estos cuatro archivos juntos:

    src/JuggleBall.js
    src/input.js
    src/player.js
    src/ball.js

Si ya integraste la primera versión, REEMPLAZA LOS CUATRO ARCHIVOS.
No basta con cambiar solo JuggleBall.js.

2. IMPORTAR Y MOSTRAR

En un módulo JavaScript de tu aplicación (ajusta la ruta):

    import { JuggleBall } from "./src/JuggleBall.js";

    const game = new JuggleBall({
        touchOffsetY: 110 // Opcional: valor predeterminado
    });

    game.start();

El offset se aplica solo en pantallas táctiles: la raqueta se dibuja por encima del dedo. Con mouse no se aplica offset. Cerca de los bordes la raqueta se limita al área visible.

3. OCULTAR AL TERMINAR LA CARGA

El sitio debe decidir cuándo termina la operación. Ejemplo dentro de una función async:

    const game = new JuggleBall();
    game.start();

    try {
        await loadAppData();
    } finally {
        game.destroy();
    }

loadAppData() es un ejemplo, NO una función del juego.
Si deseas reutilizar la misma instancia más tarde, usa game.stop() en vez de game.destroy().

4. API

    game.start();    // mostrar/iniciar
    game.stop();     // detener y ocultar
    game.destroy();  // detener y eliminar el Canvas

La API pública no cambió respecto de la primera versión.

5. PUBLICACIÓN Y CACHÉ

Al desplegar la actualización, asegúrate de que el navegador reciba los cuatro archivos nuevos.
Si usas bundler, utiliza su versionado/hash de assets. Si sirves ES Modules directamente,
invalida la caché del módulo principal Y sus dependencias (input.js, player.js, ball.js).
Cambiar solo la URL del HTML no garantiza renovar los módulos.

El importmap con ?v=... de demo/index.html es específico de la demo;
NO se copia automáticamente al instalar src/ en otra web.

6. PRUEBAS ANTES DE ENTREGAR

- Desktop: mouse, colisiones, puntuación, Start/Stop/Destroy.
- Android real: movimiento táctil, separación dedo/raqueta, límites del Canvas,
  rebotes, puntuación y desaparición del overlay al terminar la espera.
- Confirmar que no hay errores de importación ni código antiguo en caché.

IMPORTANTE: el Canvas es un overlay de pantalla completa que captura el puntero
mientras está activo y normalmente bloquea la interacción con la página debajo.

Para documentación detallada, consultar README.md.
